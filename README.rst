Lamina Standard Recommendation
================================================================================

这里保存 Lamina 相关规范草案。每份 LSR 描述一部分语言、运行时、标准库或相关组件的约定。

在线文档由 Sphinx 生成, 访问 `https://lsr.laminasys.org/ <https://lsr.laminasys.org/>`_ 查看。

本地构建
--------------------------------------------------------------------------------

.. code-block:: sh

   python -m pip install -r requirements.txt
   python -m sphinx -b html . _build/html

构建完成后，打开 ``_build/html/index.html`` 查看文档。
