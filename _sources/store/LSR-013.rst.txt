================================================================================

- 作者 Ziyang-Bai

摘要
--------------------------------------------------------------------------------


定义 Lamina 集合类型。集合表示有限、无序、去重、同构的值集合；可用于数学表达、CAS 多结果返回和标准库容器。

技术规范
--------------------------------------------------------------------------------


1. 范围
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~


本规范定义有限集合 ``set<T>``。区间使用 ``interval<T>`` [5]_；无限集合、条件集、全集和带重数集合由对应的 CAS 或标准库规范定义专门表示。

集合用于无序、去重的同构结果；元组按固定位置区分多个结果，支持同构与异构的元素组合 [4]_。需要顺序或重数的结果使用向量，或由具体接口定义包含值与重数的组合。

2. 集合类型
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~


集合类型写作 ``set<T>`` [1]_。

.. code-block:: text

   let a set<int> = {1, 2, 3}
   let b set<Expr> = {x, x + 1}


- ``set<T>`` 表示元素类型为 ``T`` 的集合
- 集合元素必须可比较相等
- 集合不保证迭代顺序
- 集合中不存在重复元素
- 集合值默认不可变

3. 集合字面量
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~


集合字面量使用花括号。

.. code-block:: text

   let ints = {1, 2, 3}
   let nums = {1, 1/2, 3}
   let empty set<int> = {}


- 非空集合按元素类型统一推导 ``set<T>``
- 空集合必须由上下文推出元素类型，否则需要显式类型标注
- 无法统一元素类型时报错
- 集合字面量中的重复元素只保留一个

4. 元素类型统一
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~


集合元素必须统一为单一元素类型。

- 数值元素按 LSR-000 [1]_ 数值塔统一
- ``Expr`` 与可提升为 ``Expr`` 的元素混合时，整体可提升为 ``set<Expr>``
- 不可比较相等的类型不得作为集合元素
- 若元素类型没有明确相等语义，必须报错

5. 集合运算
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~


.. list-table::
   :header-rows: 1

   * - 运算
     - 说明
     - 示例
   * - ``in`` / ``not in``
     - 元素从属
     - ``2 in {1,2,3}``
   * - ``subset``
     - 子集判断
     - ``{1,2} subset {1,2,3}``
   * - ``|``
     - 并集
     - ``{1,2} | {2,3}``
   * - ``&``
     - 交集
     - ``{1,2} & {2,3}``
   * - ``-``
     - 差集
     - ``{1,2} - {2}``
   * - ``xor``
     - 对称差
     - ``{1,2} xor {2,3}``


- ``|``、``&``、``-``、``xor`` 的两个操作数必须是集合，元素类型必须相同或可统一，结果为统一后的 ``set<T>``
- ``in`` / ``not in`` 的右侧必须是集合，左侧元素类型必须可与右侧集合元素类型统一，结果为 ``bool``
- ``subset`` 的两个操作数必须是集合，元素类型必须相同或可统一，结果为 ``bool``

6. 集合相等
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~


集合相等忽略元素顺序。

.. code-block:: text

   {1, 2, 3} == {3, 2, 1}   # true


- 两个集合元素类型必须相同或可统一
- 两个集合包含相同元素时相等
- 元素比较使用元素类型的相等性语义
- 集合相等不得依赖迭代顺序
- ``Expr`` 元素去重与比较使用结构相等；具体 CAS 操作可按自身规范使用数学等价判定 ``===`` [6]_ 归并结果
- ``rule`` 元素按 LSR-016 [7]_ 定义的左右 ``Expr`` 结构相等去重

7. 集合推导式
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~


集合推导式产生集合值。

.. code-block:: text

   let squares = { x^2 for x in {1, 2, 3} }


- 推导式结果元素按表达式类型统一
- 推导式输入必须可迭代
- 推导式结果自动去重
- 集合推导式不得产生无限集合

8. 多结果返回
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~


Lamina 函数返回单个值。多个同类数学结果按无序、去重的集合语义组织时，返回类型为 ``set<T>`` [2]_。

.. code-block:: text

   func roots(expr Expr, var Expr) -> set<Expr>
   func solve(eq Expr, var Expr) -> set<Expr>


- 按固定位置区分的结果使用元组，支持同构与异构的元素组合
- 需要排序或保留重复值的结果使用向量；需要显式重数时，由接口定义值与重数的组合
- 普通数学函数直接返回结果值；类型冲突、操作超出支持域及求值失败沿 LSR-018 [3]_ 的错误传播规则处理

CAS 中有限可枚举的解集使用 ``set<Expr>``，复数根遵循 LSR-010 [8]_。

.. code-block:: text

   sym x
   let rs = roots(x^2 - 1, x)    # {-1, 1}


- 求解接口证明解集为空时，返回空 ``set<Expr>`` 作为正常结果
- 求解接口必须在当前算法与预算内确认完整解集后返回结果；完整性处于待定状态时，诊断 ``SetResultInconclusive`` 并沿错误路径传播
- 若结果有定义域条件，条件表达由调用的具体标准库规范定义

9. 有限性
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~


``set<T>`` 表示有限集合；可相等元组可作为集合元素 [4]_。

- 区间使用 ``interval<T>``，条件集和全集等数学对象应由 CAS 或标准库定义专门类型 [5]_
- CAS 在确认结果有限且枚举完整后返回 ``set<T>``；其他求解状态沿错误路径传播

10. 诊断
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~


- ``SetElementTypeMismatch``：集合元素类型统一失败
- ``SetOperandTypeMismatch``：集合运算的操作数类型校验失败
- 元素类型必须具备相等语义，校验失败时必须诊断；基于哈希的实现还须满足该类型的哈希契约，使哈希去重与相等判定保持一致
- ``SetResultInconclusive``：完整解集判定处于待定状态

错误名称可映射到 LSR-018 [3]_ 的统一诊断与故障传播机制。
