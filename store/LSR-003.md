## 摘要

定义 C/C++ 扩展的最小交付、接口映射与内存/所有权约束。

## 技术规范

### 1. 最小交付物

最小交付：

- 动态库（编译生成的 `.dll/.so/.dylib`，符号建议按C ABI导出）
- Lamina 模块声明文件（默认文件名为module.lm）

推荐目录（非强制）：

- `[root]/module.lm`
- `[root]/src/`
- `[root]/include/`（可选）

### 2. 接口映射语法（必需）

在 `module.lm` 中使用 `static`绑定动态库
编写动态库代码，需要包含Lamina的核心头文件"lmx.h"，内部具有lamina的一些api与类型定义。


#### 3 接口示例
假设有动态库 libadd.so，内有
LmInt add(LmInt a, LmInt b);函数

```lamina
static "add"

func so_add(a int, b int) -> int = "add"

# 等于号后面为动态库的导出符号
```

### 4. 与其他 LSR 的关系

- LSR-000：核心类型系统、值语义，复合引用语义
- LSR-004：标准库定义，扩展可作为补充实现
- LSR-008：量纲剥离规则（扩展无量纲入参场景）
