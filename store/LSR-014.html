LSR 014 - 运算符规范¶

基本信息¶

  • LSR 编号 014

  • 标题 运算符规范

  • 作者 Ziyang-Bai

  • 状态 草案

  • 类型 标准规范

  • 创建日期 08-11-2026

  • 归属项目 编译器、标准库、CAS

摘要¶

定义 Lamina 中数学表达式和普通表达式可使用的运算符、分隔符、关键字型运算符、优先级和结合性。Lamina 源码和标准文档示例都必须使用本规范列出的 token。

技术规范¶

1. 范围¶

本规范定义 Lamina 源码层运算符集合。标准库函数名、CAS 内部表示和错误消息文本不由本规范强制。

实现不得接受未列入本规范的数学符号作为运算符替代写法。

以下示例使用合法 token。

let a = x^2 + 1
let b = x <= y and y != 0
let c = item in values
let d = 2 * x * sin(x)

  • <= 是合法源码运算符

  • != 是合法源码运算符

  • and、or、not 是逻辑运算关键字

  • &&、|| 不属于 Lamina 核心逻辑运算符

  • 乘法必须显式写作 *

集合字面量 {} 表示空集合时必须由上下文确定元素类型。集合推导式中的 for 和 if 按核心语言推导式规则解析。

5. 显式乘法¶

Lamina 不提供隐式乘法。任何乘法都必须写出 *。

2 * x       # 合法
2x          # 非法
2 * (x + 1) # 合法
2(x + 1)    # 非法
x * sin(x)  # 合法
x sin(x)    # 非法

该规则同时适用于 Lamina 源码和任何接收表达式文本的库接口。

6. 优先级¶

优先级从高到低如下：

  1. 后缀：()、.、[]、'、.'

  2. 幂：^、.^

  3. 一元：+、-、not、!

  4. 乘法：*、/、//、%、\\、.*、./

  5. 加法：+、-、.+、.-

  6. 比较：==、!=、<、<=、>、>=、.==、.!=、.<、.<=、.>、.>=

  7. 从属：in、not in

  8. 逻辑与：and

  9. 逻辑或：or

  10. 管道：|>

  11. Binding 构造：=>

  12. 绑定、赋值和函数箭头

比较和从属运算不得隐式链式解析。

a < b < c       # 非法
a < b and b < c # 合法

表达式位置的 => 构造 Binding 值，语义由 LSR-011 定义 [5]。 match 分支中的 => 不按表达式运算符解析，由 LSR-005 定义。

7. Expr 直接定义¶

Expr 允许由 Lamina 表达式直接定义，不需要通过标准库字符串解析函数创建。

sym x
let expr = x^2 + 1
let roots set<Expr> = {-1, 1}
let domain = std.interval_closed_open(0, 1)
let call = max(x, y, 0)

当期望类型为 Expr 时，数值字面量、符号、函数调用和集合可以构造符号表达式；区间通过普通的标准库函数调用构造。具体提升边界由 LSR-016 定义 [4]；本规范只规定可用 token 和表面语法。

本规范不要求标准库提供通用的表达式字符串解析入口。若实现内部或第三方库接收表达式文本，该文本不得扩展本规范列出的运算符 token，乘法仍必须显式写作 *。

8. 保留与禁止¶

以下 token 在核心语言中保留，未定义语义前不得被库代码重新解释：

  • ..

  • ...

  • ?:

  • ??

  • ::

  • @

以下写法不属于核心运算符：

  • &&

  • ||

  • **

  • 隐式乘法

  • 未列入本规范的数学符号

Lamina 源码和表达式文本中的幂运算固定为 ^。

使用未列入本规范的 token 必须产生词法或语法错误。实现不得把未知 token 当作标识符、函数名或库可重载运算符继续解析。
